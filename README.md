# Chulent Bowl Fantasy Football Stats

A mobile-friendly stats site for our public ESPN fantasy football league.

- **Site:** https://cb-meb.github.io/chulentbowl/
- **Repo:** https://github.com/cb-meb/chulentbowl
- **ESPN league ID:** 104163
- **Season shown:** 2026 (current season only)

## How it works

1. A GitHub Actions workflow (`.github/workflows/update.yml`) runs `fetch_data.py` every Tuesday and Wednesday at 11:00 UTC. It can also be run by hand from the **Actions** tab (**Update league data**, then **Run workflow**).
2. `fetch_data.py` reads the league from ESPN with the `espn-api` library, runs the playoff simulation, and saves everything to `data.json` in the repo.
3. `index.html` loads `data.json` and builds every table and chart in the browser. GitHub Pages hosts the site.

The week drop-down at the top lists every completed regular-season week, and a new week is added each time the data updates. Every table and chart shows data cumulative **through the selected week**. The selection defaults to the latest completed week.

### Files

| File | Purpose |
| --- | --- |
| `index.html` | The whole front end: layout, styling, and all calculations except the playoff odds |
| `fetch_data.py` | Pulls ESPN data, runs the playoff simulation, writes `data.json` |
| `.github/workflows/update.yml` | Schedule and steps for the weekly update |
| `data.json` | Generated by the workflow. Do not edit by hand |

## League rules built into the calculations

- 14-week regular season. Only regular-season weeks are shown.
- Top 6 teams make the playoffs. Seeds 1 and 2 get byes.
- **Bonus win:** each week, the 5 highest scorers get a bonus win and everyone else gets a bonus loss. If teams tie for 5th, all tied teams get the bonus win.
- Official standings = head-to-head results plus bonus results. Ties count as half a win in sorting. The tiebreaker is total points for.

## What's on the page

### 1. Weekly scores table
- One row per team. Columns are W1 through the selected week, then average, sample standard deviation (divides by n&minus;1), min, and max.
- Default sort is team name A to Z. Tap any column header to re-sort.
- Five league rows at the bottom (min, max, median, average, standard deviation across all teams for each week). They stay at the bottom regardless of sort, and the right-hand summary columns are blank in those rows.
- Each week's top 5 scores are highlighted (the bonus-win teams).

### 2. Standings (two tables)
- **Official standings (left):** Win and Loss include bonus results, so they should match ESPN. The Bonus win column shows how many of the wins were bonus wins.
- **Head-to-head standings (right):** head-to-head record only, sorted by wins with points for as the tiebreaker.
- **Standings diff** (right table): official rank minus head-to-head rank. Positive means the team ranks higher in head-to-head than in the official standings.
- **Leadership** (both tables): wins minus all-play wins.
  - *All-play wins:* each week, a team earns the share of the other teams it outscored (top scorer 1.00, lowest 0.00, tied scores count half). These are summed through the selected week.
  - *Official table:* (official wins &divide; 2) &minus; all-play wins. Official wins are halved because each week carries two results, one head-to-head and one bonus.
  - *Head-to-head table:* head-to-head wins &minus; all-play wins.
  - Positive means more wins than scoring would predict.

### 3. Power rankings
- **Power score (out of 100)** = 50% all-play win % + 30% average score over the last 3 weeks (fewer in Weeks 1 and 2) + 20% official win % (bonus included).
- Before weighting, each component is rescaled so the league's lowest team is 0 and highest is 1. The table shows the raw, unscaled values.
- Ties break by points for. Change is spots gained or lost since the previous week.
- The line chart shows each team's power rank by week. It's hidden when Week 1 is selected. Tap a line or team name to highlight it.

### 4. Playoff odds
- **Table:** the chance each team finishes in each place of the official standings. Places 1&ndash;2 (byes) and 3&ndash;6 (playoffs) are shaded in different colors. Make playoffs is the sum of places 1&ndash;6.
- **Chart:** make-playoffs odds week by week through the selected week. Hidden when Week 1 is selected.
- **Method:** for each completed week, 10,000 simulated seasons play out the rest of the real schedule.
  - Each team's weekly score is a random draw (normal distribution, floored at 0) around its average, using its own standard deviation.
  - Early in the season, each team's average and spread are blended toward the league's. The blend weight is weeks played &divide; (weeks played + 4), so the team's own numbers count for more as the season goes on.
  - Simulated weeks award head-to-head wins and bonus wins the same way the real standings do.
  - Teams are ranked by official wins with points for as the tiebreaker.
- Once all 14 weeks are complete, the odds become exact 0% and 100% results.

## Settings you may want to change

At the top of `fetch_data.py`:

| Setting | Current value | Meaning |
| --- | --- | --- |
| `LEAGUE_ID` | 104163 | ESPN league ID |
| `YEAR` | 2026 | Season to pull. Change it each year |
| `PLAYOFF_TEAMS` | 6 | Teams that make the playoffs |
| `BYES` | 2 | Top seeds with a bye |
| `BONUS_N` | 5 | Top weekly scorers who get a bonus win |
| `SIMS` | 10000 | Simulated seasons per week |
| `PRIOR_WEEKS` | 4 | How strongly early-season team averages are pulled toward the league average. Higher means flatter early odds |

The power score weights (50/30/20) are in the `buildPower` function in `index.html`.

## Checks and troubleshooting

- **`CHECK:` lines in the workflow log.** After each run, the script compares its own win-loss-tie records with ESPN's standings. A line starting with `CHECK:` means a team's calculated record differs from ESPN's. Open the run in the **Actions** tab, then the **update** job, then the "Run python fetch_data.py" step.
- **`WARNING: playoff odds skipped`.** The simulation failed, but the rest of the site still updates. The odds section shows a message until the next successful run.
- **Page says it could not load `data.json`.** The workflow hasn't created the file yet, or GitHub Pages hasn't published it. Run the workflow and wait a few minutes.
- **Workflow doesn't appear in the Actions tab.** The file must be at exactly `.github/workflows/update.yml`.
- **Permission error saving data.** In **Settings &rarr; Actions &rarr; General**, set Workflow permissions to **Read and write permissions**.
- **Old version of the page showing.** Open the site in a private tab to get past the browser's cache.

## Known limits

- Team names come from ESPN, so a team that renames itself mid-season shows its latest name for all weeks.
- A week counts as complete once ESPN's current week has moved past it.
- ESPN's API is unofficial and can change. The `espn-api` library tracks those changes, so if the update breaks, a library update is usually the fix.
- Scores are shown to two decimals.
